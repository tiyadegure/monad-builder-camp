## 1. MCP server 原型：实际跑通的情况

今天把 Day 1 脑图里的最小结构落地了：

```
tasks/week4/stake-agent-mcp/
  package.json
  server.mjs
  tools/
    apriori-stake.js
```

**happy path 实际返回：**

```
输入： "Stake 1 MON into aPriori"
→ tool: apriori_stake
→ intent: { verb: "stake", amount: 1, protocol: "apriori" }
→ Moss: discover("apriori") → load() → action("stake")
→ tx 草稿:
  - to: 0x0c65a0bc65a5d819235b71f554d210d3f80e0852
  - value: 1 ETH (1 MON)
  - data: 0x6e553f65 + encode(uint256(1e18), address(receiver))
  - receipt.estimatedShares: 0.9985 aprMON
```

**本地验证方式：**
- `node server.mjs` 启动 stdio server
- 手动发 JSON-RPC payload（`initialize` → `initialized` → `tools/call`）
- 返回的 tx 草稿和 `stake-agent.mjs` 直接运行结果一致

**诚实边界：**
- 没有包 Claude Desktop / Cursor 集成，只验证了 stdio transport 本身
- error handling 很薄：非数字金额、负数、网络超时都没有友好提示，直接 throw
- `unstake` / `claim` tool 还没写，只有 `apriori_stake`

## 2. `unstake` / `claim` 两条 tool 的设计

虽然今天没写代码，但把接口定义想清楚了：

```
apriori_unstake(amountOrShares: string, receiver: address)
→ action("unstake")
→ requestRedeem(uint256 shares, address receiver)
→ selector: 0x107703ab
→ return: { requestId, estimatedReadyBlock }

apriori_claim(requestId: number, receiver: address)
→ action("claim")
→ redeem(uint256[] requestIds, address receiver)
→ selector: 0x492e47d2
→ return: { claimedAmount, requestIds: [requestId] }
```

**不确定点：**
- `requestRedeem` 的 `shares` 参数是“全部赎回”还是“部分赎回”？文档没明确说 partial vs full，需要看 contract 实现或主网 tx 样例。
- `redeem` 的 `requestIds[]` 是否支持单元素数组？理论上支持，但主网 happy path 还没跑。
- unbonding epoch 时长：aPriori 文档提到“~1 epoch”，但 Monad 的 epoch 长度没查到明确数字（是时间还是区块数？）。

这些不确定点不阻塞 Day 2 交付，但会在 Decision Log 里标成“假设”。

## 3. 2 分钟 Demo Video 脚本（初稿）

Demo 的核心不是“代码多复杂”，是“评委在 60 秒内看懂这是什么”。脚本设计：

| 时间 | 画面 | 台词/字幕 |
|------|------|-----------|
| 0:00-0:15 | 终端窗口：`node server.mjs` | "This is an AI Agent that understands natural language and generates verifiable on-chain transactions." |
| 0:15-0:45 | 另一个终端：发 MCP `tools/call` payload | User: "Stake 1 MON into aPriori" → Agent returns tx draft + 0.9985 aprMON estimate |
| 0:45-1:15 | 浏览器：Monad Explorer 搜索 proxy address | "The transaction draft targets the verified aPriori vault. Anyone can verify the selector on-chain." |
| 1:15-1:45 | 同屏：PR #104 diff + 单测截图 | "The adapter is already submitted to Moss with 10/10 unit tests and mainnet e2e." |
| 1:45-2:00 | 黑屏 + 项目名 + GitHub 链接 | "AI Agent + verifiable DeFi. Built with Moss Framework on Monad." |

**录屏注意事项：**
- 不要用 `/dev/session` 这种临时地址，用固定的 localhost 演示
- RPC 端点提前 ping 通，避免演示时超时
- 备选方案：如果 MCP stdio 演示不稳定，直接放 `stake-agent.mjs` 运行录屏

## 4. 关键认知

- **Day 1 的“评估”在 Day 2 变成了“真实约束”。** MCP stdio transport 比想象的简单，但“让评委现场交互”比写 server 更难。Demo 脚本改为录屏而非 live demo，降低环境风险。
