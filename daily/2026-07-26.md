### 4. Week 3 第一个可检查 Demo 定义

**Demo 名称**：aPriori 质押 Agent — 自然语言入口原型

**可检查项**：
1. 用户输入 "Stake 1 MON into aPriori" → Agent 返回 `to: 0x0c65...` / `selector: 0x6e553f65` / `value: 1 MON` / `≈0.93 aprMON`
2. 用户输入 "Compare Morpho vs Aave" → Agent 返回研究结论卡片（固定利率 vs 可变利率 / immutable vs 可调参数）
3. 全程不碰私钥、不广播，只在终端输出可验证交易草稿

**验收标准**：队友能在 10 分钟内跑通以上两条指令并看懂输出。
